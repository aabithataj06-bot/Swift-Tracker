# SwiftTracker Website

Open `index.html` in Chrome. No install needed.

Pages: index.html (home), track.html (tracking), book.html (booking form), contact.html (about, contact, FAQ).
Files: css/style.css, js/app.js.

Sample Parcel IDs: PRC-00001 to PRC-00004. New bookings are saved in the browser (localStorage) and can be tracked with the new Parcel ID.

Hosting: drag the whole folder to Netlify Drop (app.netlify.com/drop).
This is the front-end demo; the real data/automation lives in the Salesforce project (swift-tracker.zip).
